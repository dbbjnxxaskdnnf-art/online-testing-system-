# Quizly на Python (Streamlit)

Это самостоятельная Python-версия Quizly. React-версия сайта остаётся в проекте без изменений.

## Возможности

- русский, английский и казахский языки;
- четыре викторины;
- регистрация и вход;
- роли ученика и учителя;
- учитель может создавать собственные тесты с вопросами и вариантами ответов;
- созданные тесты появляются у учеников в общем списке;
- прохождение вопросов с проверкой ответа;
- личный результат ученика;
- таблица результатов для учителя;
- сохранение пользователей и результатов в `python_quiz_data.json`.

## Запуск

Установите зависимость:

```bash
pip install -r requirements-python.txt
```

Запустите сайт:

```bash
streamlit run python_app.py --server.port 5000
```

В Replit можно запускать его с портом окружения:

```bash
streamlit run python_app.py --server.port $PORT --server.address 0.0.0.0
```

Эта версия предназначена для демонстрации. Для настоящей защиты ролей и результатов нужна серверная база данных и авторизация.
